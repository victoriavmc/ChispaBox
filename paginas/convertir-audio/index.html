1. Elegí el audio

Antes de cargar

  • Podés usar cualquier archivo de audio o de video: OGG, MP3, MP4, M4A, WAV, FLAC, WebM, AAC, AMR, etc.
  • Se convierte un archivo por vez. Para archivos muy pesados, la conversión puede tardar.
  • Si el video tiene varias pistas de audio, se usa la primera.

2. Opciones

Para WAV y FLAC no se usa. Convertir a un formato con pérdida no recupera calidad que el original ya no tiene.
