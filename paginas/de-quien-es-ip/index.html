Consultar el titular

1. IP o dominio

Servicios externos. La consulta va a rdap.org, que la redirige al registro regional que administra esa IP. Si escribís un dominio, primero se resuelve con dns.google. Ningún dato se guarda en ChispaBox.

2. Resultado

El titular es quien tiene asignado el bloque. Si el bloque fue reasignado a un proveedor, aparece el proveedor. El correo de abuso sirve para reportar spam, ataques o contenido ilegal desde esa red.
