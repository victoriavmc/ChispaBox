Revisar puertos de un servidor

1. Servidor y puertos

Límites de esta prueba. Con la versión local de ChispaBox se abre una conexión TCP real a cada puerto. En la versión pública, un navegador no puede abrir conexiones TCP cualquiera: allí solo se intenta una conexión HTTPS y un puerto con otro protocolo aparece como «Sin respuesta». No reemplaza a un escáner de red como nmap.

Con la versión local de ChispaBox se hace una conexión TCP real a cada puerto. En la versión pública solo se puede probar HTTPS desde el navegador.
