1. Elegí la imagen

Antes de cargar

    La imagen no sale de tu equipo. El original nunca se modifica.

    2. Quitá el fondo

    Método

    Tocá la imagen en el color que querés quitar. Después usá «Quitar el color elegido».

    Color elegido

    Tocá una zona del fondo: se quita esa zona y las partes del mismo color que estén conectadas con ella.

    Baja: solo colores casi iguales. Alta: también tonos parecidos.

    3. Vista previa

    100 %
    Resultado Original

    Los cuadros grises y blancos indican transparencia. Tocá la imagen con el pincel o con el cuentagotas según el método elegido.

    4. Descargar

    Sin transparencia, las zonas quitadas se rellenan con este color.
