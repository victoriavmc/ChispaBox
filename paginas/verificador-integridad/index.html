Verificar un archivo

Antes de cargar

  • Tamaño máximo: 500 MB.
  • El archivo no se sube: el hash se calcula en tu navegador.

2. Hash SHA-256 calculado

Todavía no elegiste un archivo.

3. Comparar con el hash esperado
